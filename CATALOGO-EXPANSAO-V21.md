# Expansão do Catálogo Voxxel — V21

Status: **planejamento aprovado para precificação**  
Quantidade: **36 novos produtos**  
Catálogo após ativação: **54 produtos**

## Regra desta etapa

Nesta etapa os produtos são definidos apenas por **nome, categoria e proposta comercial**.

Ainda **não** ficam definidos:
- preço;
- porte;
- material final;
- peso estimado;
- tempo de impressão;
- acabamento;
- margem.

Esses campos serão calculados na próxima rodada para os **54 produtos da loja**, usando uma metodologia única.

Os 36 itens abaixo **não devem entrar no catálogo público antes da precificação**.

## Decoração & Utilitário — 12 novos produtos

### D01 — Porta-Chaves Modular de Parede
Sistema compacto de parede com módulos para chaves, chaveiros e pequenos objetos de entrada. Pode receber módulos adicionais sem substituir a base.

### D02 — Bandeja Organizadora Empilhável
Bandeja modular para acessórios, escritório, gavetas e pequenos objetos, com encaixe para empilhamento vertical.

### D03 — Organizador Modular de Maquiagem
Organizador de bancada com divisórias para pincéis, batons, lápis e itens pequenos, permitindo combinação entre módulos.

### D04 — Porta-Cápsulas de Café Vertical
Organizador vertical para cápsulas de café, pensado para ocupar pouca área de bancada e facilitar a retirada individual.

### D05 — Suporte Ajustável para Livro e Tablet
Suporte de mesa com múltiplas posições de inclinação para livros, tablets, receitas e leitura em bancada.

### D06 — Kit Porta-Copos Geométricos
Conjunto de quatro porta-copos com desenho geométrico e base de armazenamento para manter o kit organizado.

### D07 — Vaso Autoirrigável Compacto
Vaso decorativo de pequeno porte com reservatório separado para reduzir a frequência de rega de plantas pequenas.

### D08 — Porta-Joias Modular com Divisórias
Sistema de bandejas para anéis, brincos, correntes e acessórios, combinável conforme a quantidade de peças.

### D09 — Organizador de Mesa para Controles Remotos
Base de bancada com espaços separados para controles de TV, ar-condicionado e outros dispositivos domésticos.

### D10 — Dispenser Compacto de Sacolas
Organizador vertical para armazenar e retirar sacolas reutilizáveis ou plásticas de forma mais organizada.

### D11 — Suporte de Parede para Vasos Pequenos
Suporte decorativo para pequenos vasos, pensado para composição de parede e instalação em conjunto.

### D12 — Luminária Lithophane Personalizada
Estrutura decorativa para lithophane personalizado a partir de fotografia enviada pelo cliente. Componentes elétricos não inclusos.
