# Voxxel — Refinamento visual V7

## Ajustes desta rodada

- Atendimento flutuante reduzido para um balão roxo com ícone branco, sem o botão textual grande.
- Header público passou a usar símbolo Voxxel + wordmark claro `VOXXEL`, melhorando contraste sobre o fundo escuro.
- Prévia da calculadora foi substituída por um visualizador volumétrico em canvas com wireframe, point cloud, partículas, scan line e proporções baseadas nas dimensões informadas.
- O visualizador continua sendo apenas uma representação dimensional; não é uma renderização do STL enviado.
- Catálogo foi redesenhado para seguir a mesma linguagem visual da home: hero editorial, filtros compactos, cards premium, melhor hierarquia de imagem/preço/estoque e CTA para projeto personalizado.
- Checkout recebeu ajustes globais de superfície e tipografia para manter continuidade visual com home e catálogo.
